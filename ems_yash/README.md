# HEV Reinforcement Learning

Reinforcement learning based energy management strategy for a Hybrid Electric Vehicle (HEV).

## Environment

- Python 3.x
- PyTorch
- Gymnasium
- NumPy
- Pandas
- SciPy
- Matplotlib

## Project Structure

- `data/raw/` - Original driving-cycle datasets
- `data/processed/` - Cleaned and processed driving cycles
- `src/data/` - Data processing utilities
- `src/environment/` - HEV RL environment
- `src/models/` - Neural network models
- `src/agent/` - RL agents
- `notebooks/` - Analysis and visualization
- `results/` - Experimental results
